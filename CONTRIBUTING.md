# Contributing to Team Tokenizing_Our_Tears

Thank you for your interest in contributing to our BUBT Bengali NLP Safety Challenge 2026 project!

## How to Contribute

1. **Fork the Repository**: Create your own branch from `main`.
2. **Environment Setup**: Install dependencies via `pip install -r requirements.txt`.
3. **Notebook Experiments**: Make improvements to the model architecture, data preprocessing, or feature engineering in new notebooks.
4. **Pull Requests**: Open a pull request describing your changes and experimental results.

For any questions, feel free to reach out to the team members listed in `README.md`.
